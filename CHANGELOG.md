# Changelog

All notable changes to Daymark are documented in this file.

## [0.1.0] - 2026-11-24

### Added
- **Phase 0:** Initialized Tauri 2 + React 19 + TypeScript + Vite project scaffold.
- Configured application identifier `com.daymark.app` and product name `Daymark`.
- Added Tailwind CSS v4 styling with light and dark theme support.
- **Phase 1 Rust Backend:**
  - Integrated `rusqlite` with bundled SQLite, WAL mode, foreign keys, and busy timeout.
  - Implemented transactional migration runner with `001_initial.sql` creating `tasks`, `projects`, `categories`, `reminders`, `activity_logs`, and `settings` tables.
  - Created typed task domain models (`Task`, `CreateTaskInput`, `UpdateTaskInput`, `TaskFilters`, `DashboardSummary`).
  - Implemented repository layer supporting full task CRUD, completion, reopening, filtering, and dashboard metrics.
  - Added unit test suite for task lifecycle, validation, idempotency, and dashboard calculations.
- **Phase 1 React Frontend:**
  - Built desktop application shell with navigation sidebar, header, search bar, and theme switcher.
  - Implemented typed `taskService` invoking Tauri backend IPC commands.
  - Built `DashboardPage` displaying real-time metrics (Total, Due Today, Overdue, Completed Today) and today's task list.
  - Built `TasksPage` with status tabs (All, Pending, Completed), priority filtering, search, and empty states.
  - Built `TaskModal` for creating and editing tasks with date/time pickers and priority selection.
  - Implemented task card with complete/reopen toggling, edit modal trigger, and deletion confirmation.
- **Phase 2 Projects & Categories:**
  - Implemented Rust SQLite repository and IPC handlers for Projects and Categories CRUD.
  - Added unique constraint enforcement on category names and `ON DELETE SET NULL` cascades for task assignments.
  - Added unit test suite covering project and category lifecycle, validations, and referential cascades.
  - Created typed frontend services (`projectService`, `categoryService`) and TypeScript interfaces.
  - Added `ProjectModal` and `CategoryModal` supporting 10 curated color themes.
  - Added `ProjectBadge` and `CategoryBadge` indicators to task cards.
  - Integrated Project and Category sections into `Sidebar` with quick creation, editing, deletion, and scoping.
  - Added Project and Category dropdown filters and active filter indicators to `TasksPage`.
- **Phase 3 Calendar & Recurring Tasks:**
  - Implemented recurrence calculation engine in Rust supporting `daily`, `weekdays`, `weekly`, and `monthly` schedules.
  - Automated generation of subsequent recurring task instances upon completion inside the database transaction, preserving series linkage via `recurrence_series_id`.
  - Added backend unit tests (`test_recurrence_calculation`, `test_recurring_task_completion_creates_next_task`).
  - Added `CalendarPage` featuring interactive Month and Week views with due date indicators, status toggling, and date-prefilled quick add.
  - Integrated recurrence selection in `TaskModal` and recurrence indicator badges in `TaskCard`.
  - Added Calendar view to the navigation sidebar and application routing.
- **Phase 4 Reminders & Native Notifications:**
  - Added `Reminder`, `CreateReminderInput`, and `DueReminder` Rust models and TypeScript interfaces.
  - Implemented SQLite repository methods for reminder CRUD, atomic delivery tracking, and missed-reminder recovery.
  - Built background low-frequency scheduler thread running every 15 seconds with `Arc<Mutex<Connection>>` concurrency.
  - Integrated `tauri-plugin-notification` for native desktop notifications conforming to GNOME/FreeDesktop standards.
  - Implemented typed Tauri IPC commands: `create_reminder`, `get_reminder`, `list_reminders_for_task`, `delete_reminder`, `dismiss_reminder`.
  - Implemented client `reminderService` with permission requests and `reminder-delivered` event listener.
  - Enhanced `TaskModal` with reminder presets (at due time, 15m, 30m, 1h, 1d before, and custom datetime) and active reminders management.
  - Created in-app floating reminder alert banner in `App.tsx` with one-click task completion and dismissal.
  - Added unit test `test_reminder_lifecycle_and_duplicate_protection` verifying scheduling, due querying, atomic delivery, and cascade deletion.
- **Phase 5 System Tray, Global Shortcut, Autostart & Memory Optimization:**
  - Built native system tray (`src-tauri/src/tray.rs`) featuring Open, Quick Add, Separator, and Quit actions.
  - Added left-click toggle on the system tray icon to hide/show and focus the main window.
  - Implemented window close interception (`WindowEvent::CloseRequested`) to keep Daymark running quietly in the background tray.
  - Integrated `tauri-plugin-global-shortcut` registering `Ctrl+Shift+Space` to trigger Quick Add Task from any active window or application.
  - Added typed settings commands (`is_autostart_enabled`, `set_autostart_enabled`, `get_setting`, `set_setting`) interacting with `tauri-plugin-autostart` and SQLite `settings` table.
  - Optimized memory consumption across Rust and SQLite:
    - Set `PRAGMA cache_size = -2000` (capped to 2MB in-memory cache), `PRAGMA mmap_size = 0`, and `synchronous = NORMAL`.
    - Added periodic passive WAL checkpointing in the scheduler thread every 15 minutes to reclaim dirty memory pages and truncate WAL files.
    - Added frontend visibility listener in `App.tsx` pausing active reloads and rendering while the window is hidden to minimize background CPU and RAM usage.
  - Added `SettingsModal` in the frontend accessible from the sidebar to manage Linux autostart, view hotkeys, and inspect memory metrics.
  - Added unit test `test_settings_table_crud_and_conflict_upsert` (total 14 unit tests passing).
- **Phase 6 Analytics, Backup & Packaging:**
  - Implemented Rust analytics aggregation models (`ProductivityOverview`, `DailyCompletionStat`, `ProjectDistributionStat`, `PriorityDistributionStat`) and parameterized SQLite repository queries.
  - Built `AnalyticsPage` with Recharts featuring Swiss Editorial + Obsidian Workshop styling:
    - Key metrics bar: completion rate %, current & best activity streak (days), completions this week and month.
    - 14-day / 30-day interactive Daily Completion Trend Area Chart with gradient fill and custom dark tooltip.
    - Project Breakdown progress bars and Priority Distribution bar chart.
  - Implemented dual-format database backup and restore system:
    - Portable JSON workspace export and transactional import (`BackupData`, `RestoreResult`) supporting both clean replace and non-destructive merge modes.
    - Live, zero-lock, defragmented SQLite snapshots utilizing `VACUUM INTO ?1`.
    - Integrated native GNOME file save and open dialogs via `tauri-plugin-dialog`.
    - Local snapshot archive manager listing backups from `~/.local/share/com.daymark.app/backups/` with one-click restore.
  - Updated `SettingsModal` with tabbed navigation ("General & System" and "Backup & Data").
  - Added unit test suite covering analytics aggregation, JSON backup/restore lifecycle, and SQLite snapshot integrity (17 unit tests passing).
  - Verified Debian `.deb` package creation via `pnpm tauri build`.
- **Visual Design System (Swiss Editorial + Obsidian Workshop):**
  - Integrated Manrope (headings), Inter (interface text), and IBM Plex Mono (timestamps, dates, metadata).
  - Established unified Light (`#F3F0E9`, `#EAE7DF`, `#FAF9F5`, `#252522`, `#77746D`, `#C64D38`, `#D9D4C9`) and Dark (`#20211F`, `#252623`, `#2B2C29`, `#F0EEE7`, `#A5A49B`, `#D17B54`, `#41413D`) theme tokens in Tailwind v4.
  - Replaced native browser date/time inputs with custom `DateTimePicker` component featuring quick date presets (Today, Tomorrow, Weekend, Next Week), month navigation, editorial calendar grid, quick time presets (9 AM, 12 PM, 5 PM, 8 PM), fine-grained hour/minute steppers, and AM/PM segmented controls.
  - Implemented dynamic React Portal viewport positioning with real-time coordinate recalculation on window resize, scroll, and zoom (`Ctrl +` / `Ctrl -`), guaranteeing popovers never overflow screen boundaries or clip at any zoom level.
  - Redesigned collapsible sidebar, compact aligned header, flat task rows with custom checkboxes, and modal dialogs with 4px–8px radii.
  - Replaced generic metric cards with a unified editorial statistics grid.
- **Documentation:**
  - Created `README.md`, `AGENTS.md`, `docs/ARCHITECTURE.md`, `docs/DATABASE.md`, `docs/DEVELOPMENT.md`, and `docs/ROADMAP.md`.
